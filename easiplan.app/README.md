
# EasiPlan

EasiPlan is a Windows desktop application that is installed on a user’s computer using Microsoft TM OneClick technology. 

This allows updates to be deployed seamlessly from a hosted url and ensures that clients always run the latest version of the software. 

It connects to a MySQL database that is hosted either in an on-premise or cloud server.
